⚠️ Status Diagnostik Error: 16:05:00
Koneksi SSH Timeout: Komputer target 192.168.27.203:22 tidak merespons (Port 22 mungkin belum dibuka atau service SSHD belum berjalan).
Salin log error ini untuk analisis atau pelaporan:
⚡ Solusi Instan (Perintah Auto-Fix PowerShell Administrator):

Jalankan di PowerShell Administrator pada komputer target untuk memastikan Port 22 terbuka dan Service SSHD aktif:

$p="$env:windir\System32\OpenSSH\sshd.exe"; if (-not (Test-Path $p)) { $p="$env:ProgramFiles\OpenSSH\sshd.exe" }; if (-not (Get-Service sshd -ErrorAction SilentlyContinue)) { & sc.exe create sshd binPath= "`"$p`"" start= auto DisplayName= "OpenSSH SSH Server" }; & "$env:windir\System32\OpenSSH\ssh-keygen.exe" -A; Set-Service sshd -StartupType Automatic; Start-Service sshd; netsh advfirewall firewall add rule name="OpenSSH-Server-In-TCP-22" dir=in action=allow protocol=TCP localport=22 profile=any; Write-Host "SSH PORT 22 AKTIF!" -ForegroundColor Green

Langkah Pengecekan & Pemecahan Masalah:

1. Pastikan PC target menyala dan terhubung ke WiFi / LAN yang sama.
2. Jalankan setup_target_ssh_1click.bat (Run as Administrator) di target.
3. Pastikan status service sshd adalah Running di target.
4. Pastikan Username & Password login Windows di Vault sudah sesuai.
